# Boccia Pocket

Статическая игра для GitHub Pages. Откройте index.html через HTTP-сервер.

## Структура

- index.html — разметка; styles.css — оформление.
- state.js, configuration.js — состояние и настройки.
- court.js, inventory.js — геометрия поля, инвентарь и доступность хода.
- online.js — комнаты, протокол, восстановление связи и серверная анимация.
- setup.js, match-setup.js — меню и подготовка матча.
- training.js, puzzles.js — тренировка и задачи.
- controls.js, input.js — кнопки, ползунки и события ввода.
- bot-simulation.js, bot-strategy.js — контактная физика для симуляции и ИИ.
- rules.js — очки и переходы матча; physics.js — цикл локальной физики.
- rendering.js — отрисовка; bootstrap.js — запуск и возврат из фона.

## Изменения и сборка

Редактируйте перечисленные исходники. Выполните `node build.cjs`, затем `node build.cjs --check`. Закоммитьте исходники вместе с обновлённым game.js. Зависимости устанавливать не нужно.

game.js — сгенерированный файл, не редактируйте его вручную. build-order.json задаёт точный порядок исходников. На этом этапе исходники разделены по ответственности, но ещё имеют общую замкнутую область состояния: сборщик оборачивает их в одну IIFE. Такой переход сохраняет существующее поведение и не создаёт глобальных переменных. Следующим отдельным этапом можно вводить явные интерфейсы между подсистемами и переиспользовать правила с сервером.

В этой структурной правке собранный JavaScript побайтно совпадает с исправленной монолитной версией. Изменения поведения онлайн находятся в предыдущем коммите.
